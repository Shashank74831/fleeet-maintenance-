Full-stack social + real-time chat platform built with MERN Stack.

### 📖 About
Connectly lets users share posts, connect with friends, and chat instantly in real-time.

### ✨ Features

- Real-time Chat (Socket.io)
- Post Feed - Like, Comment, Share
- Follow / Unfollow
- Notifications & Online Status
